# Internationalization

English is the fallback and initial appliance language. `i18n-en.json` and `i18n-fr.json` have identical keys covering login, setup, dashboard, topbar, sidebar, live server, library, maps, vehicles, mods, players, collections, backups, logs, diagnostics, settings, confirmations, notifications, errors and onboarding.

The shared `i18n.js` translates semantic `data-i18n` keys and existing UI phrases, including dynamically inserted UI through a mutation observer. `i18n-en-legacy.json` provides the English compatibility table while the historical shell is progressively migrated to semantic keys. Exact-match translation deliberately leaves external mod names, authors, BeamNG descriptions, raw BeamMP logs and technical map names untouched.

First Run will persist `default_language`; the Web setting changes only the Manager language and never the Debian locale.
