# Third-party notices

Beam-MP-Server-Manager is an independent server-management project.

## BeamMP Server

The BeamMP Server executable is not maintained by this repository. The VMware provisioning workflow downloads the selected official BeamMP Server release from the upstream BeamMP project and verifies the published SHA-256 digest before installation.

Beam-MP-Server-Manager source updates must not silently replace BeamMP Server with an unvalidated upstream release. The project tracks BeamMP Server compatibility separately.

## BeamNG.drive content

BeamNG.drive game assets are not part of this repository. In particular, official BeamNG map preview images are intentionally not committed to Git. The Manager can use locally supplied/extracted previews on an appliance without redistributing those assets through this source repository.

## Names and marks

Third-party product/project names referenced by the Manager identify interoperability targets. Their ownership and licensing remain with their respective owners/projects; the MIT license in this repository applies to Beam-MP-Server-Manager source code, not to third-party software or game content.
